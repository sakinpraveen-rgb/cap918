# PG Manager - everything you need to download to build and run the project
#
# This is a JavaScript project, so this file is NOT used by pip.
# It's a checklist: section 0 has the commands, sections 1-3 list what they download.
# npm package versions are the exact ones in package-lock.json.

# ===================================================================
# 0. QUICK SETUP COMMANDS (Windows, run in PowerShell or cmd)
# ===================================================================
# Steps A and B are enough to run the app in demo mode. C-F are optional.
#
# --- A. Install Node.js (includes npm). Close and reopen the terminal afterwards. ---
#     winget install -e --id OpenJS.NodeJS.LTS
#     node --version                         (must print v24.15+ or v22.22.3+)
#
# --- B. Install all npm packages (sections 2 and 3 below) ---
#     cd <project-folder>
#     npm ci                                 (exact versions from package-lock.json)
#
# --- C. Local backend: Docker Desktop + Supabase images ---
#     winget install -e --id Docker.DockerDesktop
#     (start Docker Desktop and wait for "Engine running", then:)
#     cd <project-folder>
#     start-backend.cmd                      (first run downloads Supabase CLI 3.1.0 + Docker images, ~5 min)
#
# --- D. Android builds: Android Studio (includes JDK 21 and the SDK Manager) ---
#     winget install -e --id Google.AndroidStudio
#     (open Android Studio once, finish the setup wizard, then in
#      Settings > Languages & Frameworks > Android SDK tick "Android 16 (API 36)")
#     cd <project-folder>
#     npm run build
#     npx cap sync android
#     cd android
#     .\gradlew.bat assembleDebug            (downloads Gradle 8.14.3 + all Android libraries)
#
# --- E. iOS builds (on a Mac only) ---
#     xcode-select --install                 (then install Xcode from the Mac App Store)
#     npm ci
#     npm run build
#     npx cap sync ios
#     npx cap open ios                       (Xcode downloads the Swift packages on first open)
#
# --- F. End-to-end tests: Playwright browser ---
#     cd <project-folder>
#     npx playwright install chromium
